# Changelog

## 0.1.0 — unreleased

Initial standalone development version. Public GitHub source publication is planned, with the
destination still pending. The package's `private: true` protects npm registry publication; this
entry is not a release announcement.

### Added

- A `work-revocation.v1` investigation of queued and retried agent work, with selected workflow
  context, exact evidence reads, model-selected experiments and host-owned verdict requirements.
- Independent destination acceptance observations ordered against a supervisor acknowledgment,
  including independently authorized work and legitimate pre-revocation acceptances.
- A supported worker-source recipe, paired before/after cases, unchanged-workload verification,
  raw-content canary checks and an inert HTML investigation report.
- `cancellation-demo`, `cancellation-trials` and `verify-cancellation` commands; authored unsafe,
  safe, incomplete-capture and blocked-work arrangements with operator labels outside model inputs.
- Explicit strict function-tool mode and request-boundary schema validation for Meta Responses.
- Installed-package checks for cancellation sources, repair/utility outcomes, trial verdicts,
  supplied-record verification and the new public library exports.
- Saved MCP 2025-11-25 tool-list imports with exact source citations, source-qualified identities,
  raw-definition fingerprints and explicit upstream/runtime discovery boundaries.
- Evidence-bound checkpoints, dependency change investigations, profile-review gates and a five-case
  revalidation demonstration separating historical findings from fresh observations.
- `import-mcp`, `checkpoint`, `assurance-diff`, `assurance-demo` and `verify-assurance` commands.
- Source-qualified client-context snapshots, capability/coverage catalogs, exact assertion citations,
  revision/window validation and bounded queries with explicit unknown boundaries.
- Read-only evidence planning and a producer-only instrumentation recipe with separate safe/unsafe
  retests, supervisor-owned attempt commitments, independent effect receipts and witness-removal checks.
- `understand`, `evidence-demo [--live]`, `verify-evidence` and an inspectable standalone HTML report.
- A TypeScript CLI and library independent of the Praesidia backend and account system.
- Versioned customer-export approval control with independent-approval, exact-request-binding and
  permitted-work criteria.
- Frozen evidence snapshots, exact citations, criterion-specific coverage checks and bounded
  investigator/skeptic coordination.
- A Meta Responses transport with explicit live execution, bounded generation, continuation handling
  and no silent provider fallback. Real Meta service execution remains pending credentialed validation.
- Synthetic reference variants and a separate loopback HTTP export application with downstream sink
  observations.
- A deterministic repair recipe for the authored HTTP example, paired before/after cases, exact diff
  and verification of unchanged expectations and preserved permitted work.
- Portable JSON reports, inert HTML rendering, JUnit exports, structural JSON Schema and manifest-based
  consistency/freshness verification.
- Twelve authored scripted regression cases, deterministic boundary tests and standalone CI setup.
- Contribution guidance, provisional private-reporting guidance, issue forms and submission/demo drafts.

### Known limits

- The flagship runs a finite owned loopback workflow. An authority read followed by dispatch does
  not provide atomic distributed fencing, global quiescence, rollback or race-free revocation.
- Cancellation CLI targets are authored examples; arbitrary production queues/frameworks and
  unregistered destinations are not automatically discovered or integrated.
- Praesidia ingestion, generic repository repair and production remediation are not implemented.
- Client context is projected from selected manifests; autonomous whole-company discovery and live
  SaaS/PDF/Office ingestion are not implemented.
- Dependency coverage is declared. The known checkpoint builder and retest adapter cover one authored
  workload; comparison does not establish current deployed behavior or production release approval.
- Scripted evaluation success measures engineering contracts, not model quality or customer outcomes.
- The separate reference application is not an OS security sandbox for untrusted code.
- Supplied-manifest verification does not establish independent authorship or reexecute a target.
- Public repository, monitored private reporting channel, live Meta evidence and an independent human
  trial must be confirmed before launch/submission.
